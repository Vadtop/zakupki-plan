## Что должно заработать

Пакет `zakupki/` существует. `load_dataset(Path("data/raw/share"), None)` читает шесть CSV
выгрузки и возвращает `Dataset` с правильными типами, датой расчёта и списком проблем данных.
`Config` хранит все пороги проекта. В `tests/conftest.py` есть фабрика маленького синтетического
набора, на которой будут писать тесты следующие таски.

Таск маленький: ~400–600 строк вместе с тестами. Не пиши спрос, прогноз, план, CLI — это другие таски.

**Прочитай `data/raw/share/README.md` целиком до кода.** Известные ловушки (проверь сам):
- в `stock_monthly.csv` нулевых остатков нет (минимум 1): строки нет = остаток 0 — это знание
  пригодится таску 02, здесь просто не выдумывай нули;
- `avg_markup_pct_12m` пустая = не продавался 12 мес → `NaN`, не 0;
- `planned_lead_days` бывает отрицательным — здесь не чинить, только загрузить.

## Критерии приёмки

- [ ] `pyproject.toml`: пакет `zakupki`, `requires-python = ">=3.11"`, зависимости pandas, numpy; dev — pytest, ruff; ruff `line-length = 110`
- [ ] `Config` — frozen dataclass ровно с полями и значениями из `interfaces.md`, константы статусов там же; `with_overrides(min_markup_pct=30, z=None)` меняет только непустые поля
- [ ] `load_dataset` на реальных данных (`today = 2026-08-13`): 791 SKU, `avg_markup_pct_12m` пустой у 378 строк (NaN), `month` — `Period[M]`, даты — `Timestamp`
- [ ] `detect_data_date` возвращает последнюю дату из `receipts.receipt_date` и `orders.order_date` (на реальных данных — 2026-08-01); `load_dataset(..., today=None)` ставит её в `ds.today`, при явном `today` (2026-08-13) берётся он
- [ ] При заданном `today` продажи с месяцем позже месяца `today`, приходы и заказы с датой позже `today` отброшены (тест на синтетике)
- [ ] Нет файла → `DataError` «Нет файла <имя> в <папка>»; нет колонки → `DataError` с именем колонки и файла (тесты)
- [ ] Битые строки (неизвестный `sku_id` в продажах, неразбираемая дата) отброшены и описаны в `ds.issues` по-русски с числом строк (тест)
- [ ] `tests/conftest.py`: фикстура-фабрика `make_dataset(...)`, собирающая `Dataset` из маленьких списков словарей (несколько SKU, 2–3 года продаж, остатки, заказы, приходы, поставщики) — без чтения файлов
- [ ] Тест реальных данных пропускается, если `data/raw/share` нет
- [ ] Проверка зелёная: `python3 -m ruff check zakupki tests && python3 -m pytest -q`
