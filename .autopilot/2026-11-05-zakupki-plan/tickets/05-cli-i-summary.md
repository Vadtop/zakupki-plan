# 05 — Команда запуска и сводка summary.md на реальных данных

**Требования:** R10, R11, R45, R50, R51, R59i
**Зависит от:** 04b
**Зона:** `zakupki/cli.py` `zakupki/__main__.py` `zakupki/report.py` · `tests/test_cli.py` `tests/test_real_data.py`
**Волна:** 5
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

`python3 -m zakupki run --data data/raw/share --today 2026-08-13 --no-llm` проходит по всей
реальной выгрузке без ошибок и пишет в `out/` файлы `plan.csv`, `risks.csv` и `summary.md`
со сводкой цифр. Дашборда, пояснений модели и истории снимков здесь нет — их добавит таск 06,
но в `cli.py` оставь для них места в порядке шагов (`interfaces.md`, раздел `cli`).

~300–400 строк с тестами. `plan.py`, `simulation.py`, `forecast.py`, `supply.py`, `demand.py`, `data.py` не меняй —
нашёл в них ошибку → опиши в `CONCERNS`, не чини.

## Из брифа, дословно

> «`python -m zakupki run --data data/raw/share --today 2026-08-13` → `out/`
> (dashboard.html, plan.csv, risks.csv, summary.md) + снимок в `out/history/<дата>/`»

> «Проверка на реальных данных: прогон по всему набору без ошибок, сводка цифр в `out/summary.md`.»

> «**«Сегодня» для расчёта = дата данных (2026-08-13), параметром.** Не системная дата.»

> «Один и тот же вход → один и тот же план.»

## Разделы спецификации

Истории 1, 3, 30 (флаги CLI), 31, 48 (без dashboard.html и снимка), 54.
Границы — `interfaces.md`: `zakupki/cli.py`, `zakupki/report.py`. В этом таске
`write_summary(..., summary_text="", stats={"mode": "template", "calls": 0, "cached": 0, "errors": 0}, diff=None, ...)`.
