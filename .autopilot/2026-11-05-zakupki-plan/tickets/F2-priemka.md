## Критерии приёмки (расхождения приёмки, дословно)

- [ ] R10/R08 — без --today дата расчёта 01.08 вместо 13.08; run_daily.ps1, cron, workflow и README идут без --today.
      Условие: README и SKILL.md показывают основную команду с `--today 2026-08-13`; `scripts/run_daily.ps1` принимает параметр `-Today` (или переменную окружения `DATA_DATE`), `scripts/cron.example` и `.github/workflows/plan.yml` — переменную `DATA_DATE`, и передают её в `--today`; если дата не задана — CLI считает от даты данных, как сейчас, но печатает заметную строку-предупреждение по-русски: дата взята из последнего заказа/прихода (ДД.ММ.ГГГГ), для точного расчёта передайте `--today`. Системная дата в расчёт не идёт. Тест на предупреждение.
- [ ] R26/R05 — ИЗБЫТОК только при остатке > 0: 3 обогревателя с нулевым остатком, ~1000 шт. в пути и покрытием 35,7 мес — ЗАПАС В НОРМЕ.
      Условие: избыток считается по покрытию с учётом заказов в пути и не требует `stock_now > 0` (plan.py:~105), и в статусе, и в риске ИЗБЫТОК; мёртвые по-прежнему не избыток. Тест: нулевой остаток + большой заказ в пути → ИЗБЫТОК.
- [ ] Проверка зелёная; прогон на реальных данных; новые числа по статусам и рискам — в контракте («было → стало»).
