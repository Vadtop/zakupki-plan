# План закупок

## Запуск

```
python -m zakupki run --data data/raw/share --today 2026-08-13 [--out out] [--no-llm]
```

Свежая выгрузка кладётся в `data/raw/share/` (шесть CSV). `--today` — дата выгрузки, передавай всегда. Без него дата берётся из последнего заказа/прихода
(на этих данных 01.08 вместо 13.08), и CLI печатает предупреждение.
Результат: `out/dashboard.html`, `plan.csv`, `risks.csv`, `summary.md`, копия в `out/history/<дата>/`.
Ошибка данных печатается по-русски, код выхода 2. Код запускай в песочнице или в своём окружении Python 3.11+.

## Как читать результат

Основной статус у SKU один, по старшинству сверху вниз; остальные сработавшие лежат в `flags`.

| Статус | Что значит |
|---|---|
| МЁРТВЫЙ | нет продаж 12 месяцев; не закупать, остаток распродать |
| НИЗКАЯ НАЦЕНКА | наценка ниже порога; автозаказа нет, `need_qty` — справочно |
| РИСК ДЕФИЦИТА | склад опустеет раньше, чем придёт заказ; `gap_months` — длина «дыры» |
| ЗАКАЗАТЬ СЕЙЧАС | дата заказа в ближайшие 30 дней |
| ИЗБЫТОК | запаса с учётом заказов в пути больше, чем плечо + покрытие + 6 мес. |
| ЗАПЛАНИРОВАТЬ | заказ позже, дата в `order_date` |
| ЗАПАС В НОРМЕ | заказ не нужен |

Колонки `plan.csv`: `order_qty` — сколько заказать (шт.), `order_date` — до какой даты; `stock_now` — остаток;
`on_order` — в пути, `on_order_expected` — в пути с поправкой на надёжность поставщика; `lead_days` — плечо;
`cover_months` — на сколько хватит запаса; `stockout_date` — когда кончится; `safety_stock` — страховой запас;
`reliability` — доля поставленного поставщиком; `need_qty` — потребность до отсечений; `explanation` — пояснение.
`МАЛО ИСТОРИИ` в `flags` — оценка грубая. Просроченные заказы поставщиков — в `risks.csv`.
Цифры считает только код; пояснение модели ничего в плане не меняет.

## Параметры

Пороги — поля `Config` в `zakupki/config.py`; в коде других порогов нет.

| Поле Config | Смысл | Флаг CLI |
|---|---|---|
| `today` | дата расчёта | `--today` |
| `min_markup_pct` | порог наценки, % | `--min-markup` |
| `default_cover_days` | покрытие по умолчанию, дней | `--cover-days` |
| `z` | коэффициент страхового запаса | `--z` |
| `lead_default_days`, `lead_min_days`, `lead_max_days` | плечо, если нет данных, и его границы | нет |
| `order_now_window_days` | окно «заказать сейчас», дней | нет |
| `overdue_shift_days` | на сколько переносится просроченный заказ | нет |
| `excess_extra_months` | запас сверх плеча и покрытия для ИЗБЫТКА | нет |
| `horizon_months` | горизонт календаря | нет |
| `short_history_months` | меньше — флаг МАЛО ИСТОРИИ | нет |
| `llm_batch`, `llm_timeout_s` | размер пачки и таймаут вызова модели | нет |

Остальные поля без флага меняются правкой `config.py`. После правки порогов прогони тесты:
`python -m ruff check zakupki tests && python -m pytest -q`.
